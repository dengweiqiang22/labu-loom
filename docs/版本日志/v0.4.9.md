# labu-loom v0.4.9

## 修复

- 修复 Windows 工作区边界结构解析错误，避免主动移动生成无效坐标并导致窗口移动失败。
- 主动移动前校验起点和目标坐标，异常坐标不再传入 Tauri 窗口接口。
- 修复 Vite 热更新替换画布后 Pixi 仍绑定旧画布、Live2D 角色消失而只剩背景的问题。
- 页面卸载或画布变化时完整释放并重建 Live2D 渲染器。

## 验收

- Windows 开发实例热更新后，Live2D 角色仍能正常显示。
- 用户主动开启休息提醒后，连续活跃达到阈值会显示选择式休息提示。
- 休息提醒继续默认关闭，并服从互动开关、窗口状态、陪伴模式、频率上限和段内去重。

## 数据与隐私

- 不新增持久化字段。
- 不保存具体按键、鼠标坐标、单次事件时间或完整鼠标轨迹。
