## 本次更新

- 发布首个 labu-loom Windows 版本，保留对上游 BongoCat 项目的必要归属说明。
- 完成产品名称、应用标识、数据目录、代码仓库和发布链路的独立化。
- 增加可持久化的键盘与鼠标监听开关，用户可以随时暂停输入响应。
- 接入用户主动触发的检查更新入口，并使用 labu-loom 专用密钥签名更新产物。
- 取消进入设置时自动弹出的管理员指南，只有用户主动查看时才显示。

## 数据与隐私

- 不接入上游更新服务，不读取屏幕、窗口标题、文档或剪贴板内容。
- 输入监听开关只控制宠物响应，本版本不保存具体按键、鼠标轨迹或输入历史。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
