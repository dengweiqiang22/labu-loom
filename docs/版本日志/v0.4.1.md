## 本次更新

- 记忆页面新增“共同回忆”视图，并作为默认入口。
- 展示已有陪伴记录覆盖范围和最多四条近期结构化记忆。
- 保留独立的记忆管理视图以及修改、忘记和清除能力。
- 补齐简体中文、繁体中文、英文、葡萄牙文和越南文界面文案。

## 数据与隐私

- 共同回忆只读取已有日、周、月聚合和结构化记忆，不新增持久化字段或派生副本。
- 页面不展示生产力评分、原始输入事件或精确活动时间线。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
