## 本次更新

- 增加基于共同回忆模型的宠物视角自然总结。
- 在共同回忆页面展示本地固定模板总结，并补齐五种语言文案。
- 总结只在展示时即时派生，不新增持久化字段。

## 数据与隐私

- 自然总结只消费既有日、周、月聚合与结构化记忆。
- 不生成或保存自由文字，不请求在线模型或其他网络服务。
- 清除本地记忆或聚合数据后，总结会同步消失。
- 不读取或记录具体按键、鼠标轨迹、屏幕内容、窗口标题或剪贴板内容。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
