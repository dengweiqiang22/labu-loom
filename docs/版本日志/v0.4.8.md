# labu-loom v0.4.8

## 修复

- 修复多个 Git 工作树调试时共享开发配置，导致内置模型路径指向已删除工作树、桌宠主体无法显示的问题。
- 模型加载失败后不再错误进入就绪状态；界面会显示明确提示，并允许直接重试。
- 加载新模型前清理旧背景和按键贴图，避免失败时只残留局部图层。

## 开发体验

- 链接工作树使用独立的 Tauri 开发数据目录，不再覆盖主工作区的模型配置。
- Tauri 内部开发和构建钩子复用当前 pnpm，避免重复依赖 Corepack 命令。

## 已知问题
