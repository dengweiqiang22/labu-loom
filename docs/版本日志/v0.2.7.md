## 本次更新

- 增加安静、陪伴和活跃三种模式，并在应用重启后保留用户选择。
- 建立统一行为调度，支持优先级、打断恢复、冷却和频率上限。
- 增加有限范围自主移动，宠物会尊重位置锁定、偏好位置和当前屏幕边界。
- 建立只存在于内存中的活跃、缓和与空闲状态，让陪伴节奏响应输入强度。
- 修复小窗口滚动条挤压模型画布的问题。

## 数据与隐私

- 行为状态、调度队列、冷却和移动目标只存在于当前运行内存，不写入磁盘。
- Windows 隐私验收确认 Store 和应用日志中不存在具体按键、鼠标轨迹或原始事件载荷。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
