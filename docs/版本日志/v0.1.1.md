## 本次更新

- 优化手动检查更新失败时的提示，不再直接显示底层插件的英文错误。
- 为简体中文、繁体中文、英文、葡萄牙文和越南文补充本地化提示。
- 更新失败不会阻塞应用启动、桌面陪伴或本地设置功能。

## 更新说明

- 本版本仍然只在用户主动点击时检查更新，不会启动后自动请求或强制安装。
- 更新产物继续使用 labu-loom 专用签名进行完整性验证。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
