## 本次更新

- 增加连续工作后的本地动作暗示：仅在内存中累计连续活跃时长。
- 达到阈值后，在陪伴/活跃模式下尝试播放温和的休息类动作，并服从既有行为冷却与频率上限。
- 安静模式或缺少匹配动作时自然跳过，不新增持久化字段。

## 数据与隐私

- 连续工作时长只存在于当前运行内存，进入空闲后清除，不写入日聚合精确时间线。
- 不读取或记录具体按键、鼠标轨迹、屏幕内容、窗口标题或剪贴板内容。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
