## 本次更新

- 偏好设置页改为按需加载，并拆分 antd / vue / live2d 相关生产构建分包。
- 模型导入与加载失败时展示稳定本地化提示，避免把技术堆栈直接显示给用户。
- 评估并处理主包体积：主入口体积下降，仍保留既有超过 500 kB 的构建提醒作为观察项。

## 数据与隐私

- 不新增持久化字段。
- 不读取或记录屏幕内容、窗口标题、应用名称或剪贴板内容。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
