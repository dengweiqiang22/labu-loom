## 本次更新

- 建立统一的瞬时输入事件模型，让键盘与鼠标反馈使用一致的内部语义。
- 完善输入监听的启动、暂停、重复启动和失败恢复流程。
- 合并高频鼠标移动事件，减少事件积压以及宠物反馈抖动。
- 改善更新检查错误分类，避免把远端更新服务异常统一提示为本地网络问题。
- 统一开发环境为 Node.js `24.16.0` 和 pnpm `11.19.0`。

## 数据与隐私

- 输入事件只在内存中短暂参与宠物反馈，不保存具体按键、事件序列或完整鼠标轨迹。
- 暂停监听或组件退出时会清除尚未消费的瞬时输入状态。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
