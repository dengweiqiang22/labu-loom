## 本次更新

- 增加可选的明确休息提醒，默认关闭，需用户主动开启。
- 连续忙碌达到阈值后，可发起一次可忽略的选择式休息询问，同一连续活跃段内不连续追问。
- 安静模式、窗口穿透或关闭互动时不会出现休息提醒。

## 已知问题

- Windows 实机验收发现：连续活跃达到阈值后，内部提醒调度与互动计数会正常触发，但提醒气泡可能没有显示。`0.4.5` 当前不应作为已通过验收的稳定版本，待修复界面呈现链路后复验。

## 数据与隐私

- 新增设置字段 `restRemindersEnabled`（默认 false），记忆 schema 版本升至 5。
- 连续活跃时长仍只存在于内存；不新增精确工作时间线持久化。
- 不读取或记录具体按键、鼠标轨迹、屏幕内容、窗口标题或剪贴板内容。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
