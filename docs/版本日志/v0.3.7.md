## 本次更新

- 新增低打扰的选择式互动，只提供预设选项，随时可以关闭或不回应。
- 增加可主动开启的键盘和鼠标活动统计，只保存按日、周、月汇总。
- 建立本地结构化记忆，并支持查看来源、修改、忘记、分类清除和全部清除。
- 完成互动频率、安静模式、窗口穿透和每日上限之间的协同。

## 数据与隐私

- 活动统计默认关闭，不保存具体按键、鼠标坐标、事件序列或自由文字。
- 所有活动汇总和结构化记忆只保存在本机，可在记忆管理中清除。

## 安装说明

- 当前提供 Windows x64 安装包。
- 退出正在运行的旧版本后再执行安装。
- 安装包尚未配置 Windows Authenticode 证书，Windows 可能显示 SmartScreen 提示。
